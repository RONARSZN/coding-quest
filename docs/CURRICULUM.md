# Coding Quest curriculum map

Checked 2026-10-21. This is the content plan represented by `src/course-map.ts`, not a promise that planned modules can be started.

## Current path

The current foundations pack is version 4 and contains 37 activities. It retains the original 27 quest, check, skill and content-version contracts. Progress remains schema 1. New lessons and checks are additive so an existing export can load without rewriting saved work.

The optional orientation bridge adds two activities: `pre01` introduces input, instructions and output; `pre02` traces a plain-language plan. Neither is required to enter the existing route. The five available course modules are:

| Module | Focus | Checkpoint / project |
| --- | --- | --- |
| Web foundations | HTML structure, CSS appearance, visible values | Fictional product card; explain content, spacing and displayed value |
| JavaScript behavior | Values, conditions, functions and click events | Fictional stock-and-total card with changed requirement |
| Small collections | Arrays, objects, input guards and boundary tests | Fictional order estimator with product selection and delivery rule |
| Problem solving | Pseudocode, loops, tests, AI review and changed-rule transfer | Fictional event-seat planner; fresh shortfall task and later spare-capacity review |

The modules depend on independent evidence from the prior boss or its fresh variation, not accumulated XP. A solution reveal does not count as independent evidence. The app records self/coach assessments and check results; automated checks cannot establish that an explanation is honest or complete.

The route stays with JavaScript for web work. React and TypeScript, then Node.js and PostgreSQL, appear as planned stages with no playable lessons or Start actions yet. Local tools, Git, APIs, server-side validation, access control, persistence, deployment and capstone work are not taught by this pack.

## Video and transcript decisions

The supplied [video](https://youtu.be/xtMISNS6ir8), titled “If You Want To Become A Software Engineer In 2026, Do This,” was evaluated through Mark's attached `video_transcript.docx`. The transcript emphasizes computing foundations, learning to break down problems, choosing one focused programming path, building projects while learning, and proving skills through actual work. Those principles shape the sequence here: learn a concept before using it, trace an example, predict, edit, test, explain, then transfer the idea in a project.

The video mentions Python, but also identifies JavaScript as a sensible frontend/full-stack choice. Coding Quest keeps the existing JavaScript path because Mark's stated goal is practical web tools. Python can become an optional branch for a specific automation or data project; it is not a reason to restart. The transcript's salary anecdotes and sponsor-linked self-ratings are not used as course requirements or evidence of mastery. Job applications and networking remain outside this learning app.

The video URL could not be retrieved for direct viewing during this review. This interpretation relies on the supplied transcript; it does not claim that the video itself was watched.

## External study references

These are optional supplements. The links were checked on 2026-10-21; provider catalogs, enrollment rules and prices can change.

- [Harvard CS50x 2026](https://cs50.harvard.edu/x/2026/) is a free OpenCourseWare course designed for learners with or without prior programming experience. Its Week 0 materials include computational thinking, inputs and outputs, representation, algorithms, pseudocode, functions, variables, conditionals, loops and events. The larger course also covers C, Python, SQL, web development and a final project. A free CS50 Certificate has assignment and final-project requirements; the optional verified edX certificate is paid. Use Week 0 selectively for extra computing context; do not treat the full language sequence as a prerequisite. See the [2026 FAQs](https://cs50.harvard.edu/x/faqs/) and [certificate requirements](https://cs50.harvard.edu/x/certificate/).
- [Codédex JavaScript](https://www.codedex.io/javascript) is a practice and design reference. Introductory JavaScript chapters are free; later chapters and some projects require Club access. On the Philippines pricing page, the monthly Club option displayed PHP 599/month and the annual option PHP 295.75/month equivalent on 21 October 2026; the annual total was not inspected. Billing and localized prices can change. Coding Quest does not require a subscription.
- [freeCodeCamp's learning catalog](https://www.freecodecamp.org/learn/) offers free study. Its current [JavaScript](https://www.freecodecamp.org/news/freecodecamps-new-javascript-certification-is-now-live/) and [Responsive Web Design](https://www.freecodecamp.org/news/freecodecamps-new-responsive-web-design-certification-is-now-live) certifications include lessons, workshops, labs, reviews, quizzes and five required projects before an exam. The exams are closed-book and timed, run in a downloadable desktop app, allow one attempt per week and are subject to staff review. Its [Certified Full-Stack Developer route](https://www.freecodecamp.org/learn/full-stack-developer-v9) continues through front-end libraries, Python, relational databases, back-end/API work and a capstone; it is a substantial optional path, not a prerequisite here.

The app may describe provider access in broad terms, but should not promise a current price, certificate, employer recognition or job outcome. Recheck official provider pages before publishing any time-sensitive access or credential claim.
